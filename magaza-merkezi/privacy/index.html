Magaza Merkezi Privacy Policy

Last updated: 5 November 2026

Magaza Merkezi is a private internal tool used only by the developer behind these apps to monitor their own publishing accounts. It is not offered to the public, and no one else is expected to sign in to it.

Data accessed

With the account owner's permission, the tool uses two read-only Google permissions on that owner's own account:

  • AdMob (read only): app approval status and ad reports such as earnings, impressions and requests.
  • Gmail (read only): messages in the owner's mailbox, used to show store and tester notifications.

How data is used and stored

The data is shown on a dashboard on the owner's own computer and stored only there, together with the sign-in token. It is not used for advertising, is not sold, and is not shared with third parties. The tool never sends, changes or deletes email and never changes AdMob settings.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account permissions.
